# 网站留言入口

首页“联系我”右侧的“找到我”卡片中，个人简历下方的留言入口链接至用户提供的飞书表单：
https://bytedance.larkoffice.com/share/base/form/shrcn6WdJH02jhcG05ybwwtQ5Lf

点击“给我留言”在新标签页打开“给小张的留言”。表单当前标注匿名，包含留言和网站 / AI 作品建议两个问题。填写、提交和数据接收由飞书负责；网站不存储留言，不需要飞书应用密钥或用户 OAuth 授权。

表单的填写权限、字段和通知由用户在飞书侧维护。链接在 app/guestbook.tsx 中配置。更换后检查目标表单及访客可访问性。

已验证页面可打开；未代替访客提交测试留言，也未验证飞书通知送达。
